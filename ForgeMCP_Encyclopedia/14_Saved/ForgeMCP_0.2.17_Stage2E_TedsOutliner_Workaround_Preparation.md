## Ownership and assertion evidence

`TedsOutliner` is an Editor **module** of the installed experimental Engine plugin `EditorDataStorageFeatures`, not a standalone plugin. Its descriptor is `G:/Program Files/EpicGames/UE_5.6/Engine/Plugins/Experimental/EditorDataStorageFeatures/EditorDataStorageFeatures.uplugin`. The failed child log mounted that plugin at line 67. `CrashContext.runtime-xml` records an assertion at `ModuleManager.h:338` while requesting an unloaded `LevelEditor` module; its portable stack has `UnrealEditor-TedsOutliner` immediately below Core. Installed source `.../Source/TedsOutliner/Private/TedsOutlinerModule.cpp` lines 104–109 starts tab registration; lines 194–196 call `GetModuleChecked<FLevelEditorModule>("LevelEditor")`. This is a probable startup trigger. The stack is unsymbolized at function level, so that exact call is not conclusively proven. A matching `UnrealEditor-TedsOutliner.pdb` exists, but no installed symbolizer command was found in this offline pass; the minidump and PDB were left untouched.

The assertion preceded authenticated target-map and Landscape loading. Private DDC selection passed in the prior run. Stage 2E independent disk-backed height persistence remains untested.

## Why disabling the plugin fails the required safety gate

`G:/ForgeMCP/ForgeMCPDev.uproject` sets `DisableEnginePluginsByDefault=true` and explicitly enables `Fab`. The installed `Engine/Plugins/Fab/Fab.uplugin` sets `EditorDataStorageFeatures` to `Enabled=true` in its plugin dependencies. The failed log mounted Fab at line 55 and EditorDataStorageFeatures at line 67, consistent with that chain. Fab source includes data-storage feature code (`Source/Fab/Private/Teds/FabMyFolderIntegration.cpp`) and registers Fab data-storage tables. This is a concrete functional dependency, not merely a similarly named module.

An explicit clone-project `Enabled=false` override for **EditorDataStorageFeatures** would conflict with the enabled Fab plugin's declared dependency. Disabling Fab instead would violate the requirement to preserve required project plugins and the user's established Fab workflow. The installed `EditorDataStorageFeatures.uplugin` groups `TedsOutliner` with other Editor modules; no supported project-local per-module exclusion was identified in the project/plugin descriptors or inspected UnrealBuildTool module-descriptor fields. Editing an installed Engine descriptor to change just `TedsOutliner` is prohibited and would not be a project-local workaround. A configuration-only assertion fix has therefore **not** been verified.

This finding does not assert that Fab uses the TedsOutliner UI itself. It establishes that the proposed plugin-wide disablement cannot be certified to preserve Fab. It also does not establish that a hypothetical module-level override would work at runtime. ForgeMCP, Landscape, World Partition, and LevelEditor are not proven safe under the proposed disablement because the required full dependency-preservation condition fails first.
