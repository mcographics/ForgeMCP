# Experimental ForgeMCP connection recovery candidate

Plugin descriptor: 0.2.16-alpha.2 (numeric 31). Host package metadata: 0.3.16.

This package combines the current official UE 5.6.1 Forge plugin bytes with the offline-tested consolidated Python host. Native plugin DLLs are unchanged from the installed 0.2.16-alpha.1 build. R23 proved authenticated connection with the disposable StageA7G Editor, but the regular Engine test and actual indicator remain unverified. This is **EXPERIMENTAL** and not approved for official installation or production use.

Installability and upgrade from the current official plugin have not been validated. Do not deploy into a loaded Engine plugin.
