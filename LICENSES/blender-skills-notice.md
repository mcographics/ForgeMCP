# Blender Skills attribution

This repository vendors the Blender art-direction skill pack from
[arjun988/blender-skills](https://github.com/arjun988/blender-skills), snapshot
[commit `8f778d2405a214b508d4c7d80742be8e43acdd52`](https://github.com/arjun988/blender-skills/commit/8f778d2405a214b508d4c7d80742be8e43acdd52)
(94 upstream skill manifests and their supporting reference files). The upstream
repository describes the pack as 94 specialist Blender skills for multiple coding agents.
GitHub identifies the original author as Arjun Shukla (`@arjun988`).

The skill content is stored under `.agents/skills`. ForgeMCP-specific integration
notes replace upstream assumptions about unrelated Blender MCP tools; the original
skill guidance and production references remain attributed to their upstream authors.
ForgeMCP-specific skill files are original project content.

The upstream license is MIT. Its complete notice is preserved in
[`blender-skills-MIT.txt`](blender-skills-MIT.txt). This attribution does not change
the ForgeMCP project's license.
