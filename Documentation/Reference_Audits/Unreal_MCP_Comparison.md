# Unreal-MCP public command comparison

Audited 2026-10-09 against [dadf24f460da4249ce7d94ee23a025b0b6e5cdff](https://github.com/aadeshrao123/Unreal-MCP/tree/dadf24f460da4249ce7d94ee23a025b0b6e5cdff).

Majestic Forge 0.2.0 does not provide feature parity with this public repository. Its 22 MCP interfaces include Blender and API retrieval; bundled Unreal recipes are not equivalent to standalone editor commands.

Static source contains **287 decorated registrations**, **286 distinct names**, in **15 imported modules**. The README advertises 288 community commands; its 900+ figure describes a separate commercial product whose private commands are not included in this audit. Both level.py and editor_commands.py register spawn_actor with different signatures and RPC targets. Both definitions are retained, without assuming which wins at runtime.

## Original implementation priorities

1. Expand bounded asset/class/instance inspection and structured diagnostics.
2. Add previews and native transactions for existing Blueprint graphs, variables, components and function signatures; expand the supported node families deliberately.
3. Add reviewed actor, asset import/duplicate/save and material graph recipes.
4. Implement Enhanced Input, UMG, data tables/assets and Mass configuration adapters.
5. Add specialized Niagara and StateTree editors with compile diagnostics and rollback.
6. Add profiling and screenshot workflows with explicit output paths and bounds.

Deletion, rename/overwrite and saving existing work require task authorization and suitable preview/transaction/backup behavior. Custom HLSL and other code-bearing inputs need separate policy and validation; their presence in the reference does not authorize unrestricted execution here. Preserve loopback authentication, explicit session identity, main-thread native APIs, bounded requests and one-use preview/apply confirmations.

The repository is Unreal-only. Forge's Blender adapter, exact-version local API retrieval and multi-session security are separate capabilities, not substitutions for missing Unreal operations. Most GAS authoring, World Partition, PCG, animation/retargeting and other Forge roadmap requirements remain tracked separately; no private commercial feature list is treated as implemented public commands.

## Reference source caveat

search_statetree_nodes has a Python wrapper and a StateTree handler, but the top-level dispatcher does not include search_statetree in its accepted prefixes. It remains in the source-declared catalog; successful routing is unverified. The duplicate spawn_actor registrations also require runtime examination of the reference SDK to establish the effective exposed signature. Neither issue was tested against a running reference plugin.
